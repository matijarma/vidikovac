# Kiosk independent review

Before accepting the kiosk, verify these in the integrated app with the new map:

1. **Fixed invitation:** code is completely visible at 1366×768 and 1920×1080,
   including all eight characters. Keep the QR at least 240px, don’t merely crop
   the text. The 03:48 compact screenshot is better than the earlier clipped one.
2. **Content beats licence walls:** repeated full six-source attribution occupies
   a large fraction of each event/civic block. A concise per-item publisher and a
   single legible common source area should carry provenance. Full required
   credits remain accessible; repeated paragraph footers are not the product.
3. **Culture is culture:** the paired culture screenshot labelled "Danas" lists
   old exhibition start times as if happening today, and includes known Split
   and Hvar venues. Show ongoing exhibitions with end dates and a clear
   ongoing label. Today/tomorrow agenda applies to actual event dates in Zagreb.
   Neighbourhood notices remain undated. Assembly belongs to Grad; ZET notices
   belong to Promet. Do not list them as culture just because they share a feed.
4. **Glanceable composition:** the civic screenshot leaves a broad empty area
   below QR, while a narrow middle column clips the only work item. Recompose
   the space to the information. A row-fitting algorithm is a safeguard, not a
   replacement for visual hierarchy. Selected items should receive enough space.
5. **Unknown is unknown:** stale zero-warning or closure data must read as
   unconfirmed, not "no warnings · stale". That wording can still be misread as
   an all-clear. Match the app and no-JS safety meaning.
6. **Weather:** never show the raw '-' source placeholder as condition.
   Omit unavailable conditions with an appropriate label; observed speed and
   compass direction must agree with the main app.
7. **Map integration:** actual custom vector map, correct chosen-stop centre,
   readable numbered trams and sensible local route data, not an unrelated
   whole-city raster. Selection/follow API must match the map workstream.
8. **No frozen live claims:** hold estimated motion on confirmed feed outage or
   session expiry. A fresh count from another source cannot make it live again.

Author tests should measure no overlap of primary text, code and source area.
Long content should be deliberately reduced with "shown N of M" and meaningful
selection, never silently hidden at the bottom of an arbitrary box.
