# Kaj ima? Product redesign, 17 September 2026

## Approved brief

The owner approved a light-led, high-contrast redesign of the whole public product.
The public kiosk remains useful before and after pairing. Scanning grants a personal
session; explicit presentation is separate. Another direct scanner can take over
only after confirmation. Private navigation never mirrors automatically.

Landscape overview: approximately 60% local map and a separate transport board;
40% weather, upcoming activity, neighborhood/civic information and a scannable QR.
Persistent place/time header and safety footer. Portrait is a separate composition.
Phone destinations: Sada, Promet, Događanja, Još; Kvart through location and Još.
Desktop exposes all six domains and does not retain a competing map sidebar.

Keep Manrope, real sources, attributed exports, ten/five-minute sessions, privacy,
no-JavaScript safety, Croatian/English and lightweight mode. No new feeds, accounts,
tracking, framework replacement, or changes to the submitted application.

### Findings fixed during the critique loop

The impeccable pass led to distinct compact/portrait compositions, a separate
transport board below the map, a useful weather/local summary beside the QR,
and an explicit useful-row floor. The selected route moved out of the narrow
QR column. Phone search remains visible in the sheet's peek state; keyboard
focus raises it without waiting for an animation.

Map attribution starts collapsed on interactive maps, with a localized,
44px native disclosure. Public screens keep readable attribution. Startup
camera/selection requests survive delayed renderer initialization; a person's
later movement wins. Asset failures stop claiming that a map is still loading.

Presentation receipts track what the composition actually rendered, including
missing transport selections and later source removal/recovery. Creating a
new screen resets its revision sequence and ignores the old beacon's callbacks.
Initial idle state no longer remounts a useful overview during authentication.

The final live capture exposed old ultramarine building/vegetation fills still
present on the interactive night map. Those were replaced with the charcoal,
mineral and vegetation roles; the daylight road/building fills were aligned too.
A regression test now bounds map-surface OKLCH chroma and verifies label
contrast. The corrected map was inspected in the browser before recapturing.

### Test-harness corrections

The final suite retains all scenarios. Obsolete auto-mirroring/layout assertions
were updated to the approved behavior, not skipped. Layout measurements use
the rendered browser and source readiness, not sleeps or hidden content.

Local scenarios have independent synthetic visitor networks; browsers in one
scenario still share a network. Public five-per-network and thirty-global
screen quotas remain unchanged and are separately tested. Synthetic headers
are never forwarded to the public map host. This is test/capture tooling only.

Review uses built assets (`scripts/review-server.mjs --built`), avoiding HMR
reloads. Development caches live outside Playwright's cleared `test-results`.
On Windows, stop the short-session Worker before editing or rebuilding: two
watchers writing the same `app/dist` caused a local build collision.

## Reproduce and review

Heavy checks run sequentially:

```powershell
npm run typecheck
npx vitest run --maxWorkers=1 --reporter=json --outputFile=review.local/redesign/final-tests.json
node scripts/sync-token-colors.mjs --check
npm run build
```

Start the main local Worker, then the built preview. For expiry E2E, start a
second Worker on 8788 with `APP_ENV:test`, `SESSION_MINUTES:0.2` and separate
persistence. Wait for both health endpoints before the browser suite. Keep
existing `.dev.vars` private.

```powershell
$env:REVIEW_MAP_ORIGIN='https://zagreb.aningfilm.hr'
node scripts/review-server.mjs --port 5178 --built
```

In another terminal:

```powershell
$env:E2E_APP_URL='http://127.0.0.1:5178'
$env:E2E_SHORT_URL='http://127.0.0.1:8788'
$env:E2E_NO_WEBSERVER='1'
$env:PLAYWRIGHT_JSON_OUTPUT_NAME='review.local/redesign/browser-final.json'
npx playwright test --reporter=list,json
```

Stop the short-session server before the final capture/build:

```powershell
$env:LANDING_CAPTURE_URL='http://127.0.0.1:5178'
$env:LANDING_MAP_ORIGIN='https://zagreb.aningfilm.hr'
node scripts/capture-landing.mjs
```

## Limits and release status

These are automated Chromium/mobile-emulation results and inspected screenshots,
not physical iPhone/Safari or three-metre readability measurements. A real display,
camera scan at distance, screen-reader session and Safari/WebKit review remain
appropriate before a venue pilot. Source completeness still depends on the
existing upstream feeds; the redesign does not invent missing facts.

After the rendered review, the owner explicitly authorized pushing the completed
redesign to `main` on 17 September 2026 using `$matijainfra`. The release route is
GitHub → Cloudflare Builds, never a direct deployment. Confirm the commit-specific
Workers Builds check and the live application after the push. The submitted
application directories remain untouched; the pre-existing local deletion of
`.claude/settings.json` is excluded from this release.
