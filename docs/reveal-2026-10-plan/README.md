How each file was built: one writer (Claude Opus) turned the approved plan and the master brief into the package against the tree at the base commit `4b2d1191`, verified every path and line anchor by grep, and wrote **§0 Reconciliation** as the binding text: the seams shared with the other packages (signatures from the brief §5.2, verbatim), the decisions applied, what is not built in this pass, and the merge order for the files two lanes touch. Precedence inside a file: §0, then the steps and the agent brief. Between files: the brief's §3 decisions win over any package text. Line numbers are as of `4b2d1191`; R2 forks from DR1's commit and R3/R4 from DR2's, so their anchors in files R0/R1/R2 touched must be re-read with `grep` before editing.

Rules that hold in every file: no `wrangler deploy` (deploy only by `git push` to `main` → Cloudflare Builds); no production screen created by an agent (observations use the DEV screen, `POST /api/dev/screen`, counted nowhere); `docs/prijava` and `app/prijava` untouched beyond the dated note; the presence gate, no accounts, tracking, push or route planning; no invented estimates beyond the labelled ZET estimate; Croatian standard and natural, gender-neutral for things, never "zid", never a cause word; no caveat word inside a list row; whole words, never an ellipsis; the calm-motion budget of the brief §3; the departures contract (1 to 3 departures in every reading, as cells after R1). No Claude reviewer agents: the owner's Codex session (astra) reviews and fixes each branch as it finishes and runs each deploy's gate on the integrated tree (the October model); each lane's own gate is the gate; the suite, the accept tier and one observation run once per deploy. Evidence behind every number: `review.local/reveal/analysis/` (not published).
