```js
export function shownFactsMarkdown(result, title) {}
```
`shownFacts(readings)` returns
```js
{ readings, failed, from, to,            // counts; ISO of the first and last valid reading
  hours: [{ hour,                         // 'YYYY-MM-DD HH', Zagreb
    readings, failed,
    rows: { [kind]: [id, ...] },          // distinct ids per kind, non-transit kinds only, sorted
    nonTransit,                           // distinct non-transit row ids in the hour: THE KPI
    city,                                 // the same without PROMISE_KINDS (monitored)
    facts: [fact, ...], nonTransitFacts,  // distinct `fact` values; those whose wording is not in TRANSIT_WORDINGS and not `text|...`
    reveals: { count, byKind: { advance, page }, distinct: [value, ...], minGapBeats, maxDwellMs },
    departures: { min, max } }],          // the `departures` field over the hour's valid readings
  summary: { nonTransit,                  // distinct non-transit row ids over the whole run
             fewest: { hour, nonTransit } } }
```
A reveal's dwell is (its last reading's `at` − its first's) + `ROTATION_STEP_MS` (2000); `minGapBeats` is the smallest difference between the `beat` numbers of consecutive distinct reveals (null with fewer than two); both null when the hour has none. The Markdown's last line is exactly `Fewest non-transit facts: <YYYY-MM-DD HH>:00 (<n>).`
